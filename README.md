# VoiceBridge — Простой голосовой чат на Python

VoiceBridge — это клиент-серверное приложение для голосового общения и обмена текстовыми сообщениями в реальном времени. Оно написано на Python с использованием `PySide6` для графического интерфейса и `PyAudio` для работы со звуком.



## Основные возможности

*   **Голосовое общение:** Передача голоса с низкой задержкой.
*   **Текстовый чат:** Обмен сообщениями между пользователями.
*   **Визуализация активности:** Зеленый индикатор вокруг аватара показывает, кто сейчас говорит.
*   **Выбор устройств:** Возможность выбрать конкретный микрофон и устройство вывода.
*   **Самопрослушивание (мониторинг):** Опция "Слышать себя" для проверки работы микрофона.
*   **Управление звуком:** Кнопка Mute/Unmute для временного отключения микрофона.
*   **Современный интерфейс:** Темная тема и интуитивно понятный дизайн.

## Установка

Для работы приложения необходим Python 3.8 или новее.

1.  **Клонируйте репозиторий или скачайте файлы**
    *   `vb.py` (клиент)
    *   `vb-serv-cli.py` (сервер)

2.  **Установите необходимые библиотеки:**

    Откройте терминал или командную строку и выполните команду:
    ```bash
    pip install PySide6 pyaudio
    ```

    > **Важно:** Установка `PyAudio` может потребовать дополнительных действий в зависимости от вашей ОС:
    > *   **Windows:** Обычно установка проходит без проблем. Если возникли ошибки, попробуйте установить `PyAudio` из [неофициальных бинарных пакетов](https://www.lfd.uci.edu/~gohlke/pythonlibs/#pyaudio).
    > *   **macOS:** Используйте Homebrew для установки зависимости `portaudio`:
    >     ```bash
    >     brew install portaudio
    >     pip install pyaudio
    >     ```
    > *   **Linux (Debian/Ubuntu):** Установите `portaudio` и заголовочные файлы для Python:
    >     ```bash
    >     sudo apt-get update
    >     sudo apt-get install portaudio19-dev python3-dev
    >     pip install pyaudio
    >     ```

## Как использовать

Приложение работает по принципу "клиент-сервер". Один человек (хост) запускает сервер, а остальные подключаются к нему в качестве клиентов.

### Способ 1: В одной локальной сети (например, через один Wi-Fi роутер)

Это самый простой способ для игры или общения в одном помещении.

**Для хоста (тот, кто запускает сервер):**
1.  Запустите серверный файл: `python vb-serv-cli.py`.
2.  Узнайте свой локальный IP-адрес.
    *   **Windows:** Откройте командную строку (`cmd`) и введите `ipconfig`. Найдите "IPv4-адрес" в информации о вашем Wi-Fi или Ethernet адаптере. Он будет выглядеть примерно так: `192.168.1.5`.
    *   **macOS/Linux:** Откройте терминал и введите `ifconfig` или `ip a`. Найдите свой IP-адрес (например, `192.168.0.1`).
3.  Сообщите этот IP-адрес всем, кто будет подключаться.

**Для клиентов (те, кто подключается):**
1.  Запустите клиентский файл: `python vb.py`.
2.  Введите свое имя.
3.  В поле "Server Address" введите IP-адрес, который вам сообщил хост.
4.  Нажмите "Connect".

### Способ 2: Через Интернет с помощью VPN (например, Radmin VPN)

Этот способ позволяет соединяться пользователям из разных городов и стран, создавая виртуальную локальную сеть.

**Шаг 1: Настройка VPN (делают все участники)**
1.  Скачайте и установите **Radmin VPN** с официального сайта.
2.  **Хост:**
    *   Запустите Radmin VPN.
    *   Нажмите "Создать сеть".
    *   Придумайте имя сети и пароль.
    *   Сообщите имя сети и пароль всем остальным участникам.
3.  **Клиенты:**
    *   Запустите Radmin VPN.
    *   Нажмите "Присоединиться к сети".
    *   Введите имя сети и пароль, которые вам дал хост.
4.  Убедитесь, что все участники находятся в одной сети Radmin VPN и имеют зеленый индикатор подключения.

**Шаг 2: Запуск и подключение**
1.  **Хост:**
    *   В окне Radmin VPN скопируйте свой IP-адрес (он указан прямо под вашим именем). Он будет выглядеть примерно так: `26.123.45.67`.
    *   Запустите серверный файл: `python vb-server.py`.
    *   Сообщите свой **Radmin VPN IP-адрес** остальным.
    *   Следуйте шагам Клиента.
2.  **Клиенты:**
    *   Запустите клиентский файл: `python vb.py`.
    *   Введите свое имя.
    *   В поле "Server Address" введите **Radmin VPN IP-адрес** хоста.
    *   Нажмите "Connect".

Теперь вы можете общаться так, как будто находитесь в одной локальной сети!

## Возможные проблемы и решения

*   **Не удается подключиться к серверу.**
    *   **Проверьте IP-адрес:** Убедитесь, что вы вводите правильный IP-адрес хоста.
    *   **Брандмауэр/Антивирус:** Самая частая причина. Хосту необходимо разрешить входящие подключения для Python или для порта `12345` в настройках брандмауэра Windows (или другого антивируса). При первом запуске сервера Windows обычно сам предлагает создать такое правило.
    *   **Общая сеть:** Убедитесь, что вы находитесь в одной и той же локальной или VPN-сети.

*   **Меня не слышно / я никого не слышу.**
    *   **Выберите устройства:** В выпадающих списках "Microphone" и "Output Device" выберите правильные устройства, которые вы используете.
    *   **Проверьте кнопку Mute:** Убедитесь, что вы не нажали кнопку "Mute" (она становится красной).
    *   **Системная громкость:** Проверьте уровень громкости микрофона и наушников в настройках вашей операционной системы.
    *   **Используйте мониторинг:** Поставьте галочку "Слышать себя (мониторинг)", чтобы проверить, поступает ли звук с вашего микрофона в приложение.
